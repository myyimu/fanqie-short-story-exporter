# Android 下载记录与阅读规划

- [x] 保存导出文件时取得持久读取授权，记录文件名、格式、时间和 URI；重启后仍可查看。
- [x] 添加之前保存的 TXT、Markdown、EPUB、ZIP；可移除记录而不删除原文件。
- [x] 在应用内阅读 UTF-8 TXT 与 Markdown，使用基础 Markdown 排版；大于 4 MiB 的文件交给其他应用打开。
- [x] EPUB：解析书目、目录、章节及内嵌图片，加入应用内章节导航与阅读位置。
- [x] ZIP：展示压缩包中的故事文件与导出报告，允许选择单篇阅读；包内 EPUB 也可继续阅读。
- [ ] 如有需要，再支持将 ZIP 解压到用户选择的新位置。

文件访问使用 Android Storage Access Framework。持久授权仍会在文件被移动、删除或提供方撤销访问时失效，界面会提示重新添加；卸载应用会清除应用内的下载记录，但不会删除用户保存的文件。

阅读器只显示 EPUB 的正文和常见排版，不运行书中的脚本或外部资源。ZIP 仅查看内容，不解压到磁盘。单个 TXT、Markdown 或 EPUB 章节最多读取 4 MiB；单张 EPUB 图片最多 4 MiB；整个压缩包最多 100 MiB。超限文件可用其他应用打开。
