# Android 下载记录与阅读规划

- [x] 保存导出文件时取得持久读取授权，记录文件名、格式、时间和 URI；重启后仍可查看。
- [x] 添加之前保存的 TXT、Markdown、EPUB、ZIP；可移除记录而不删除原文件。
- [x] 在应用内阅读 UTF-8 TXT 与 Markdown，使用基础 Markdown 排版；大于 4 MiB 的文件交给其他应用打开。
- [ ] EPUB：解析书目、目录、章节及内嵌图片，加入应用内章节导航与阅读位置。
- [ ] ZIP：展示压缩包中的故事文件与导出报告，允许选择单篇阅读，再决定是否支持解压到新位置。

文件访问使用 Android Storage Access Framework。持久授权仍会在文件被移动、删除或提供方撤销访问时失效，界面会提示重新添加；卸载应用会清除应用内的下载记录，但不会删除用户保存的文件。
